# Smart-contract prototype archive

This directory preserves the earlier DD.Game smart-contract and wallet-integration prototype for reference only.

It is no longer part of the active project build, the GitHub Pages website, or the current prototype scope.

## Archived contents

- `contracts/` — Solidity game and mock token contracts.
- `scripts/` — Hardhat deployment, seed, and ABI export scripts.
- `test/` — Hardhat tests for the archived contracts.
- `src/chain/` — chain config, address helpers, and generated ABI exports.
- `src/indexer/` — earlier event indexing and leaderboard generation scripts.
- `root/` — previous root package manifest, TypeScript config, Hardhat config, and env example.
- `web/` — previous web package manifest plus contract/wallet frontend integration files.

## Status

Archived only. Do not treat this as audited, production-ready, or maintained contract code. The active site is the static initial draft in `../../web/`.
